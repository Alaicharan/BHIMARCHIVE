# BHIMARCHIVE

A digital heritage tribute and archive concept dedicated to Dr. B. R. Ambedkar, featuring a modern landing page, historical storytelling, knowledge mapping, and an AI-style research assistant.

## Project files

- `index.html` — single-page site with HTML, CSS, and JavaScript
- `README.md` — project overview and run instructions

## Run locally

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Highlights

- Hero section and brand identity for BHIMARCHIVE
- Timeline and archive storytelling sections
- Knowledge graph / concept connection design
- AI assistant mock interface
- Responsive layout for desktop and mobile

## Notes

This is a static front-end concept and does not yet include a live backend or connected archival data source.
